# Calculator Internship Task

A responsive working calculator built using only:
- HTML
- CSS
- Vanilla JavaScript

## Features

- Addition, subtraction, multiplication and division
- Large equals button matching the reference layout
- Clear button
- Keyboard support
- Responsive design for phones and desktops
- Division-by-zero protection
- No frameworks or external libraries

## Run locally

Open `index.html` in a browser.
